## 理由（重要な順に3つ）

1. 設定ファイルは `teams/<チーム名>/config.json` にあり、JSONとして正しく読めます。
2. Git Bash では `test -f` が通ります。失敗するのは Python 側だけです。
3. 同じ `config.json` を Windows 形式のパス（`C:/Users/...`）で指定すると Python が読めます。

## 2. 読めない原因の確認

- 実行結果：`team-list.sh --json --scope all` は3チームを「読めない」と判定し、**一覧を出さずに拒否**しました。
- Python で直接開いて確認しました。
  - `/c/Users/Admin/.../config.json` → **FileNotFoundError**
  - `C:/Users/Admin/.../config.json` → **成功**
- 原因の場所：`scripts/team-list.sh` が Git Bash のパスをそのまま `scripts/internal/team-list.py` に渡しています。
- 実行環境：`python3` は `C:\Users\Admin\AppData\Local\Programs\Python\Python312\python`（Windows版）です。
- 影響：`team-list --scope all` が常に使えません。`team.sh <チーム名>` は個別に読めるため動きます（`handoff-test` で確認済み）。
