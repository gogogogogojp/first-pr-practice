# 依頼087 報告書：ステータスコマンドで利用枠が見えるかの試行

作成：2026-11-25 ／ Claude Code（Haiku 5.5）

## 結論

- **Claude Code：コマンドでは見えない。** `/usage` `/status` はヘッドレスで実行されず、文章として扱われた。
- **Codex：コマンドでは見えない。** `/status` も同じく文章として扱われた。
- **ただし、実行時の出力から値が取れた。** Claude は `stream-json` 出力、Codex は実行後のログで取得できた。
- 086の結論（Claudeは利用率が読めない）は**一部修正が必要**。Claudeの利用率は出力から読めた。

## 1. Claude Code

| 項目 | 結果 |
|---|---|
| `claude -p "/usage"` | **見えなかった。** 文章として扱われ、Git の `usage` フォルダを調べ始めた |
| `claude -p "/status"` | **見えなかった。** 同様に文章として扱われ、`git status` の確認に入った |
| `--output-format json` | 利用枠の値は含まれなかった（コストの値のみ） |
| `--output-format stream-json --verbose` | **見えた。** `rate_limit_event` の `utilization`（使用率） |

取得値（実行時点）：

- 5時間枠：使用 **7%**（残り約93%）／リセット **2026-11-25 02:10 JST**
- 7日枠：使用 **47%**（残り約53%）／リセット **2026-11-27 04:00 JST**

注意：

- `/usage` の試行では、Bash や Git への権限要求で止まった。意図しない操作は実行されていない。
- 試行で少額の利用（約 $0.008 相当）が発生した。

## 2. Codex

| 項目 | 結果 |
|---|---|
| `codex exec "/status"` | **見えなかった。** 文章として扱われ、`git status` の確認に入った |
| 実行後のログ（`rate_limits`） | **見えた。** 直前の実行で新しい記録が追加された |

取得値（記録時点：2026-11-24 22:43 UTC ＝ 2026-11-25 07:43 JST）：

- 7日枠：使用 **24.0%**（残り約76%）／リセット **2026-11-25 12:42 JST**

注意：

- 値は「最後に実行した時点」のもの。実行しなければ更新されない。
- `codex exec` 中に一部のコマンドが接続エラーで失敗した。値の取得には影響なし。

## 3. 完了条件の確認

- 両ツールで「コマンドで見えた／見えなかった」を判定：**完了**（上の表）
- 見えた場合の値：**完了**（Claude 5時間7%・7日47%、Codex 7日24.0%）
- 見えなかった場合の理由：**完了**（文章として扱われ、対話画面のコマンドはヘッドレスで動かない）
- 086と合わせた結論：**完了**（下記）

## 4. 086と合わせた結論

- **コマンド方式（/usage・/status）は使えない。** 両ツールとも対話画面専用。
- **実行時の出力・ログ方式は使える。**
  - Claude：`stream-json` の `rate_limit_event` から使用率を取る。
  - Codex：実行後に、最新の `rate_limits` の記録を読む。
- 結論：**ログ読みとは別に、実行時の出力から取る方式が最も実用的。**
- 086の報告書のClaude部分（利用率は読めない）は、この結果で訂正が必要。
