# Codexへの依頼

このフォルダはCodexWorker専用です。Windowsのタスクスケジューラからログオン10分後と毎時14分・44分台に起動します。ログオン中のユーザーで実行します。

依頼は直下にMarkdownファイルとして置いてください。ファイル名は `YYYY-MM-DD_NNN_短い件名.md` とします。

```markdown
# 依頼: 短い件名

## 依頼内容
対象、期待する成果物、作業範囲、制約を書く。
```

作業範囲の既定はリポジトリ内です。完了した依頼は `processed/` に移動し、日本語の報告書が `reports/` に追加されます。失敗した回の変更は確認用に残します。未コミット変更が残っている場合は次回も停止します。pushだけ失敗したコミットは次回に再送します。

このリポジトリは公開です。個人情報、業務データ、認証情報を含む依頼は置かないでください。金銭、対人操作、外部送信・公開を必要とする依頼は報告書に「要承認」と記録します。ファイルの削除と認証情報らしきファイルの読み取りは禁止です。

ログは専用作業コピーの `logs/codex-worker-YYYYMMDD-HHmm.log` に保存します。ログはGitに含めません。
