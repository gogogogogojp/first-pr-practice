## 1. ゴール：二号機ができるようになること

- ごとうがモコに一言頼むと、PCの中で作業が進む。
- ごとうは、コピペや進捗の見張りをしなくてよい。
- 完成したら、結果と証拠（変更したファイル・ログ）だけが届く。
- 例：画像の形式チェック、ファイル整理、テストの実行、ローカルのGitでの作業。

## 2. 仕上がりのイメージ（1日の流れの例）

これは案です。実際の流れは試運転で調整します。

1. **朝**：ごとうがモコに「今日の投稿の下準備をして」と頼む。
2. **最大30分後**：二号機が依頼を受け取る（30分ごとに確認するため）。
3. **作業中**：二号機が作業フォルダの画像を確認し、形式をチェックする。
4. **完了後**：二号機が結果をまとめ、モコに返す。
5. **検収**：モコが「完成か未完成か」を判定する。未完成なら直しを指示する。
6. **報告**：モコがごとうに「完成（または未完成と理由）」を伝える。
7. **最後**：投稿などの本人操作はごとうが行う。

### 用語の説明
- **指示書（CLAUDE.md・AGENTS.md）**：AIに「何をしてよいか」を書いたメモ。
- **agmsg**：PC内のAI同士が、データベース経由で連絡し合う仕組み。
- **n8n（エヌエイトエヌ）**：決まった時間に処理を動かす自動化ツール。
- **ヘッドレス**：画面を出さずに、裏で動かすこと。
- **検収**：作業の結果が「完成」と言えるかを確認すること。

## 6. できないこと・限界（正直に）

- **PCの電源が切れている・スリープ中は動かない。**
- 指示の反映は**最大30分ほど遅れる**。
- 本人確認・SMS認証・CAPTCHA（ロボットでないかの確認）は、本人の操作が必要。
- 規約で自動化が**明記して禁止**されている操作はしない。その場合は「下書きまで自動、最後は本人」の形にする。
- ChatGPTのウェブ版の自動操作はしない（正式な方法がないため）。
- 物理的な作業や、スマホアプリの中だけでできる操作は対象外。
