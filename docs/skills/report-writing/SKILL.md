# 報告書の書き方

## 保存先と名前

- 場所：`reports/`
- 名前：`YYYY-MM-DD_NNN_<日本語の件名>_Claude報告書.md`
  - 例：`2026-11-25_092_利用枠を定期的に読める仕組みの実装_Claude報告書.md`
- 件名は日本語で、内容が分かる名前にする。
- 同じ名前の報告書が既にあれば、上書きせず内容を確認してから追記する。

## 書式

```markdown
# 依頼NNN 報告書：<件名>

作成：YYYY-MM-DD ／ Claude Code（モデル名）

## 結論
- **<結果の要点を太字で1行ずつ>**

## 1. 実施したこと
## 2. 変更ファイル（表：ファイル／種類／内容）
## 3. 確認結果（数値・実行結果で書く）
## 4. 決まったこと・要承認・次にやること
```

## ルール

- 結論を先に書く。数値や実行結果で書く（「正常」だけで済ませない）。
- 完了と未確認は分けて書く。
- 試せなかった手順は「未検証」と書き、理由を1行添える。
- 認証情報の値は書かない。
- 報告書を作ったら、依頼ファイルの「## 結果」欄に要約と報告書のパスを書く。
