# 日報の書き方

## 保存先と名前

- 場所：`logs/daily/`
- ファイル名：`YYYY-MM-DD_claude-code.md`（日付ごとに1ファイル）
- その日のファイルが既にあれば、新しく作らず末尾に追記する。既存の内容は消さない。

## 書く内容（短くてよい）

```markdown
## 追記（依頼NNN）
- やったこと：依頼NNN（件名）を処理した。報告書は `reports/...`。
- 決まったこと：なし、または具体的に書く。
- 次にやること：具体的に1〜2行。
- 注意：要承認の項目や、確認できなかった点。
```

## ルール

- 認証情報の値（トークン・パスワード・鍵）は書かない。
- 「完了」と書くのは、確認が取れたものだけ。未確認は「未確認」と書く。
- Notionへの転記はしない（モコが行う）。
- 推測で書かない。報告書と依頼ファイルの結果欄を見てから書く。
