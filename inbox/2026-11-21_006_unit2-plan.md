# 依頼006：二号機の詳しい計画書づくり

## 読むもの
- `docs/UNIT2-DESIGN.md`（モコが作った二号機の設計書。このリポジトリに一緒に入っている）

## やること
設計書をもとに、二号機の「詳しい計画書」を作る。Claude Code だけで決めず、Codex とも相談すること（agmsg が使える環境なら agmsg で、無理な場合は Codex CLI を呼び出す、または意見をファイルに書かせる形でもよい）。相談した内容が分かるよう、Codex 側の意見の要点も計画書に残すこと。

## 計画書に入れる内容
1. ゴール：完成した二号機は、ごとうの代わりに何ができるようになるのか
2. 仕上がりのイメージ：ごとうが実際にどう使うか（1日の流れの例で書く）
3. 工程表：段階ごとに、何を作る・何を決めるのか
4. 時間の目安：各段階にどれくらい時間がかかりそうか
5. ごとうの指示・判断が必要になるポイントの一覧（どこで何を聞くのか）
6. できないこと・限界（正直に）
7. 費用：課金しない方針で進められるか。有料になる部分があれば明記する

## 書き方
- 中学生でもわかる、やさしい日本語で書く。専門用語には一言説明を付ける
