# 依頼126：検証と振り返りルールの試行開始

宛先：アント（Claudeワーカー1）
出した人：モコ（親方の決定を受けて）

## 決定事項
「AIチームの検証と振り返りのルール」（Duet案）を採用する。試行はアントで1週間。週1回の振り返りはモコが日曜日に行う。試行の結果を見てから、ほかのワーカーへ広げるか決める。

## ルールの内容
- ルール1：確認の基準を1か所に置く。ワーカーは main の基準を読んで自分の作業を確かめる。基準を直せるのは、親方の承認を受けたモコだけ（ワーカーは書き換えない）
- ルール2：同じ確認で3回続けてつまずいたら作業を止め、何をして・どこでつまずいたかを報告書に書いてモコへ上げる。通るまで何度もやり直さない
- ルール3：週1回（日曜）、モコが1週間分の日報と報告書を読み、同じミスが2回以上あれば原因と防ぎ方をまとめ、「ルール追加案」として親方へ出す。承認されたものだけ確認基準に足す

## やってほしいこと
1. 「確認基準.md」をリポジトリのルートに新規作成する。初版は次の5項目（モコが用意したもの。そのまま使うこと）：
   1. 依頼番号と報告書が対応している（報告書のファイル名に依頼番号と件名があり、判定が先頭にある）
   2. ファイル名・報告書名が日本語で分かりやすい
   3. 分からないことは「未確認」と書いてある（推測で書いていない）
   4. お金・対人・削除・外部公開に当たる作業をしていない（要承認のものは止めてモコへ上げている）
   5. 既存の内容を消していない／認証情報らしきファイルの中身を読んでいない
2. アントの作業手順に組み込む：報告書を出す前に main の「確認基準.md」を読み、自分の報告書を確かめる。報告書の末尾に「確認基準チェック：全項目OK」または「確認基準チェック：項目○でつまずいた（内容）」と1行書く
3. ルール2もアントの手順に明記する（3回つまずいたら止めてモコへ上げる）
4. 試行期間は1週間（2026-12-05まで目安）。ほかのワーカーへは広げない

## 注意
- 「確認基準.md」は新規作成のみ。既存ファイルの内容は消さない
- お金・対人・削除・外部公開にあたる内容は含めない。認証情報らしきファイルは読まない
- 判断できない点は決めず、モコへ上げること
