# 依頼：n8n のインストールと起動確認

## 背景
自動化の土台として、ワークフロー自動化ツール n8n をこのPCに導入したい。導入はごとう本人が承認済み。外部には公開せず、localhost でのみ使う。

## 依頼内容

0. **現状確認（最初に必ず）**
   - n8n は途中まで導入されている可能性がある。まず `docker ps` と `http://localhost:5678` の応答で現状を調べる
   - すでに動いている場合は再作成しない。不足している部分だけを補う
   - 報告には「現状／今回やったこと／完成と言えるか（言えない場合は理由）」をはっきり分けて書く

1. **Docker確認**
   - `docker --version` と `docker ps` で Docker が使えるか確認する
   - Docker Desktop が起動していない場合は、起動を試みる。起動できない場合は無理に進めず報告して止める
2. **n8nの起動**
   - 作業フォルダ `C:\Users\Admin\repos\n8n-local` を作り、docker compose で起動する
   - イメージ：`docker.n8n.io/n8nio/n8n`
   - ポート：5678、データは名前付きボリューム `n8n_data` に永続化
   - 環境変数：`TZ=Asia/Tokyo`、`GENERIC_TIMEZONE=Asia/Tokyo`
3. **確認**
   - `http://localhost:5678` にアクセスして応答があること（curl等で確認）
4. **報告ファイル** `reports/2026-11-21_n8n-install.md` をこのリポジトリに作成し、実施内容・結果・アクセスURL・起動/停止の方法・残作業（初回オーナーアカウント作成はごとう本人が行う）を書く

- ポートを外部に公開する設定はしない（localhostのみ）
