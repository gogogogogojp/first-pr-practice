# 依頼033：依頼032（チーム計画書）の作り方の追加指示。モデルを一段階上げて、往復を何周か回すこと

親方の追加指示です（2026-11-23）。このままだと大雑把になるため、計画書づくりの質を上げます。

## 追加の指示

1. **モデルを一段階上げる**：計画書の叩き台づくりと、Codexとのやり取りでは、通常の設定より一段階高いモデルを使ってください。具体的なモデル名は、PC側の現行設定から一段階上のものを選ぶこと。報告書に「現行のモデル」と「今回使ったモデル」を書いてください。
2. **やり取りを何周か回す**：叩き台 → Codexの意見 → 直し → またCodexの意見、を最低2〜3周回してください。1回の往復で終わらせないこと。
3. **各周で何が変わったか**が分かる形で記録してください（変更点の要約でよい）。
4. **親方に見せるため**：完成したら、報告書に計画書の置き場所（パス）と要点のまとめを含めてください。モコが受け取って親方に見せます。

## 注意

- 対象は依頼032の計画書づくり。他の作業（依頼020の全速作業など）の進め方は変えないこと。
