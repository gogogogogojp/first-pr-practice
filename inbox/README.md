# inbox/ の使い方

モコが依頼ファイルをここに置くと、ごとうの PC のタスクスケジューラが
30分ごとに `worker/Invoke-ClaudeWorker.ps1` を実行し、Claude Code（ヘッドレス）が処理する。
処理済みは `inbox/processed/` へ移動する。失敗した依頼はここに残る。

## 依頼ファイルの形式

ファイル名：`YYYY-MM-DD_NNN_<短い件名>.md`

```markdown
# 依頼: <件名>
- 依頼者: モコ
- 作成: 2026-11-01
- 種別: 調査 / 実装 / ファイル処理 / その他

## 依頼内容
<具体的に。対象ファイル、期待する成果物、制約を書く>

## 結果
（Claude Code がここに追記する。未処理の間は空）
```

## 安全ルール

- 作業範囲は、依頼ファイルに範囲の指定がある場合はその指定を優先する。指定がない場合の既定はリポジトリ内のみ
- 金銭・対人関係・外部への送信を伴う内容は自動実行せず、結果欄に「要承認」と書く
- このリポジトリは public のため、業務データ・顧客名を含む依頼は流さない
