# 依頼: 詳しい手順のスキル化で、毎回の読み込み量（トークン）を抑える

## 親方の希望（2026-11-25）
「他のAIに絡む部分で、スキルにした方がトークン量を抑えられるのであれば、スキルにしておいてほしい」

## 考え方
- CLAUDE.md（Claude側）と AGENTS.md（Codex側）の指示は、ワーカーが動くたびに全部読み込まれる。
- 「毎回は要らないが、特定の作業のときにだけ要る詳しい手順」まで常時読み込まれていると、その分のトークンを毎回使う。
- スキルは「名前と短い説明だけが常時読み込まれ、本文は作業に合ったときだけ読み込まれる」仕組み。そのため、詳しい手順をスキルへ移すと毎回の読み込み量が減る。

## やること
1. 現在の CLAUDE.md と AGENTS.md の分量（文字数・行数）を測り、報告書に書く。
2. 常時読み込みから外せる「詳しい手順」を洗い出す。候補：
   - 日報の書き方（形式・タグ付けのルール）
   - 報告書の形式（日本語の名前の付け方・進捗の書き方）
   - 相談（Consult.ps1）の使い方
   - agmsg の使い方
   - 知識ベース（Obsidian・Notion）の読み書き手順
   - 利用枠の読み取り手順（依頼092と関連）
3. Claude Code と Codex がそれぞれ対応しているスキルの仕組みを調べ、対応しているものはスキル化する（スキル置き場へ SKILL.md を作り、元の指示からは詳細を外して短い参照だけ残す）。
4. 常時必要な核のルール（安全・承認・作業範囲・削除しない等）は、元の指示に必ず残す。スキルへ移すのは詳細手順だけ。
5. 効果を測る：移行前後の「常時読み込み量（文字数）」を比べて報告書に書く。効果が薄いものは無理に移さない。
6. スキル化した後、対象の作業を1回試し（例：日報を書く）、スキルが正しく読み込まれて作業できるか確認する。

## 完了条件
- 分量の前後比較、スキル化した一覧、試行の結果が報告書に書かれていること。
