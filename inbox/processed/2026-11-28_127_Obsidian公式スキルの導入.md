# 依頼127：Obsidian公式スキルをパソコンのClaude Codeに入れる

宛先：アント（Claudeワーカー1）
出した人：モコ（親方がClaude Duet調べの依頼文を渡したもの）

## ねらい
Obsidianの保管場所（Vault）を、AIチームの共通のノートとして使えるようにするための第一歩。今回はプラグインを入れるところまで。

## やってほしいこと
パソコンのClaude Codeへ、Obsidian公式のスキルを入れる。手順（対話画面でのコマンド）：
- /plugin marketplace add obsidianmd/obsidian-skills
- /plugin install obsidian@obsidian-skills

進め方：
1. ワーカーの実行（claude -p の非対話形式）でスラッシュコマンドがそのまま打てない場合は、Claude Codeのプラグインの仕組み（設定ファイルやCLI）で同じ結果になる方法を調べ、その方法で入れる
2. 上記のマーケットプレイス名で見つからない場合は、出典の https://github.com/kepano/obsidian-skills（Obsidian公式のスキル置き場）を確認し、正しい入れ方を報告に書く。無理に別物を入れない
3. 入れたあとは、プラグイン一覧で obsidian が入っているか確認する
4. うまく入らなかったら、出たエラーをそのまま報告書に書く（直せそうなら直し方も書くが、無理に進めない）

## ここまでで止めること
