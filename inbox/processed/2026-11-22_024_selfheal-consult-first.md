# 依頼024：機能1「自己検知・自動修理」は、作る前にAI同士で相談すること

親方の指示です（2026-11-22）：一番の「自己検知・自動修理」については、ハチだけで考えず、モコ・Codex・ChatGPT・Claude Codeがお互いのAIを使って相談し、よりエラーの起きにくいものを作ってから実装すること。

## 手順

1. Claude Codeが、自己検知・自動修理の設計の叩き台を作る。
2. Codexに意見を聞く（Bash経由）。Codexの認証エラーがまだ直っていない場合は、その旨を報告し、その分は復旧後に回す。
3. ChatGPTの意見を取る。PC側のChatGPTセッション（Orca等）にアクセスできる場合はそこから。できない場合は、相談用の質問文をファイルに作り、報告に「ChatGPT分は未実施」と明記すること（やったことにしない）。
4. 相談で特に詰めること：
   - 今日のpull失敗（合体で止まる）のような詰まりを、どうやって自分で見つけるか
   - 自動で直してよい範囲と、止めて知らせる範囲の線引き
   - 直せなかったときに、どうやってモコ・親方に知らせるか
5. 相談の結果と最終の設計案を reports/ に出す。**実装はまだ始めない**（モコが検収し、親方の優先順位に沿って次の依頼で指示する）。
