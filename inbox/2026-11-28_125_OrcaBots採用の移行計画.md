# 依頼125：Orca Bots採用の移行計画

宛先：アント（Claudeワーカー1）
出した人：モコ（親方の決定を受けて）

## 決定事項
親方が2026-11-28に、Orca Bots（Stably AI製）を二号機チームの土台として採用することを決定した。依頼120の「評価だけ」から一歩進める。ただし、いきなり全部を移すのではなく、この依頼では「移行計画」を作るところまでを行う。移行の実施は計画の報告書をモコが検収してから、段階ごとに別依頼で出す。

## やってほしいこと
1. 現行構成の棚卸し：今の4ワーカー（アント・ハチ・オウル・Codexワーカー2）の動き方（タスクスケジューラ、作業コピー、受付inbox、モデル割り当て＝依頼118の内容）を、Orca Botsのボット構成へどう対応させるか、対応表を作る
2. 移行の段階案を作る：①試験導入（ボット1つだけ作り、小さい依頼で一巡させる）②検証（未保存の変更で止まる詰まりが消えるか、見張り・検収の分離が保てるか）③本移行（残りのボットを移す）④戻し方（うまくいかない場合に今の方式へ戻す手順）
3. 各段階の作業内容と、かかる時間の見込み（トータル何時間か）を書く
4. 注意点への対策を計画に入れること：
   - 新規ボットはフルアクセスで始まる → 作成直後に承認モードへ切り替える手順を必ず含める
   - PCがスリープするとボットも止まる → 前提として明記し、運用でどう扱うか書く
   - 試験が通るまで、今の方式（タスクスケジューラ＋作業コピー）は止めない・消さない
5. 優先順位は崩さない：①agmsg ②二号機 ③n8n。移行作業のためにagmsgの実一巡を止めないこと

## 注意
- この依頼では移行の「実施」はしない（ボットの作成・設定変更もしない）。計画作りだけ
- 削除はしない。お金・対人・外部公開にあたる内容は含めない。認証情報らしきファイルは読まない
- 判断できない点は決めず、モコへ上げること
