# inbox-claude2/ の使い方（ハチ（見張り）用の受付）

ハチ（見張り）用の Claude ワーカー（2人目）の受付です。依頼084で作成。
ごとうの PC のタスクスケジューラ（ClaudeWorker2）が、毎時09分・39分（30分間隔）に
`worker/Invoke-ClaudeWorker2.ps1` を実行する。作業コピーは `first-pr-practice-claude-worker2` です。
処理済みは `inbox-claude2/processed/` へ移動する。失敗した依頼はここに残る。

## 役割（ハチ（見張り）の担当）

- **見張り**：アント（ClaudeWorker）と Codex ワーカーのログを毎回確認する。
  滞り（直近90分以上ログが無い）と連続失敗（直近3回すべて失敗）を見つけたら `reports/` に「見張り報告」として書く。
  第一版は検知と報告まで。自動修理はしない。Claude は使わない（利用枠の節約）。
- **軽い作業**：短時間で終わる確認・調査・小さな修正だけを処理する。
- **重い実行作業**：処理しない。結果欄に「アント（ClaudeWorker）へ回してください」と書き、報告書で知らせる。

## 依頼ファイルの形式

ファイル名：`YYYY-MM-DD_NNN_<短い件名>.md`（NNN は数字3桁。inbox/ とは独立した連番）

```markdown
# 依頼: <件名>
- 依頼者: モコ
- 作成: 2026-11-25
- 種別: 調査 / 確認 / 小さな修正 / その他

## 依頼内容
<具体的に。対象ファイル、期待する成果物、制約を書く>

## 結果
（ハチ（見張り）が追記する。未処理の間は空）
```

## 結果と報告書

- 結果は依頼ファイルの「## 結果」欄に追記する。
- 報告書は `reports/YYYY-MM-DD_NNN_<件名>_ハチ報告書.md` に出す。
- 見張りの報告は `reports/YYYY-MM-DD_見張り報告.md` に出す（同じ内容は同じ日に1回だけ）。

## 安全ルール

- 作業範囲は、依頼ファイルに範囲の指定がある場合はその指定を優先する。指定がない場合の既定はリポジトリ内のみ
- 金銭・対人関係・外部への送信を伴う内容は自動実行せず、結果欄に「要承認」と書く
- ファイルの削除は行わない。認証情報らしきファイルの中身は読まない
- このリポジトリは public のため、業務データ・顧客名を含む依頼は流さない
