# Orca試験ボットへの依頼（試験用）

<!-- 依頼129で新規作成（2026-11-28）。Orca Bots移行計画（依頼125）の段階①用。 -->

このフォルダは、Orcaの試験ボット `codex2` **専用**の受付です。

- 今のCodexワーカー2（`inbox-codex2/`）とは別です。二重に拾わないためです。
- 試験ボットは、このフォルダだけを見ます。ほかの受付は見ません。
- 試験の間（段階①②）だけ使います。段階③で `inbox-codex2/` へ切り替えます。

## 依頼の置き方

ファイル名は `YYYY-MM-DD_NNN_短い件名.md`（NNNは半角数字3桁）。

```markdown
# 依頼: 短い件名

## 依頼内容
対象、期待する成果物、作業範囲、制約を書く。

## 結果
```

- 終わった依頼は `processed/` へ移します。
- 報告書は `reports/` に日本語で置きます。
- 結果は **PR方式**で戻します（段階①②）。mainへ直接は入れません。

## 守ること

- このリポジトリは**公開**です。PRの文面にも、お客様情報・業務データ・認証情報を書きません。
- 金銭・対人・外部への送信・公開・削除を伴う内容は実行せず、「要承認」と書きます。
- 認証情報らしきファイルは読みません。
- 権限が「承認を求める」になっていることを確かめるまで、依頼は置きません。
