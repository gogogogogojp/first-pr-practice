## 依頼内容

Orca試験ボット `codex2` が、受付から PR まで一巡できるかを確かめる、小さな試験です。

1. 作業は**専用の作業コピー**で行う。mainの作業フォルダ（`C:\Users\Admin\repos\first-pr-practice`）では、ブランチを切り替えない・ファイルを書かない。
   - 例：`git -C C:\Users\Admin\repos\first-pr-practice worktree add C:\Users\Admin\repos\first-pr-practice-orca-test -b orca-test/001 main`
2. 作業コピーの中で、次の報告書を**新規作成**する。
   - `reports/2026-11-28_001_一巡の試験_codex2報告書.md`
   - 中身：先頭に「判定：完成」または「判定：未完成」。次に、処理した日時、使ったモデル、承認を求められた回数（分かる範囲）、困ったこと。5〜15行でよい。
3. 作業コピーの中で、この依頼ファイルの「## 結果」欄に1〜3行で結果を書き、`inbox-orca-test/processed/` へ移す。
4. コミットし、ブランチ `orca-test/001` を push して、main 宛ての **PR を作る**（mainへ直接入れない・マージしない）。
   - PRの題：`試験001 Orcaボット一巡の確認`
   - PRの本文：やったことを3行以内。業務データ・お客様情報・認証情報は書かない（公開リポジトリ）。
5. 終わったら、PRのURLを返す。

## 制約

- 上の報告書・この依頼ファイル以外は変更しない。
- 削除・外部への送信（PR作成を除く）・公開・お金に関わる操作はしない。
- 認証情報らしきファイルは読まない。
- 迷ったら作業を止めて、止めた地点と理由を返す。
